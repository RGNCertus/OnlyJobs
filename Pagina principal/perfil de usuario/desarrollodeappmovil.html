ONLYJOBS - Desarrollo de App Móvil

Proyecto: Desarrollo de App Móvil

Creación de una app móvil multiplataforma para gestión de tareas, con diseño intuitivo, sistema de notificaciones y sincronización offline.

Funcionalidades principales:

  • Registro y autenticación de usuarios
  • Creación, edición y eliminación de tareas
  • Notificaciones push y recordatorios
  • Modo offline con sincronización en línea

Tecnologías usadas:

  • React Native
  • Redux
  • Node.js y MongoDB
  • Expo y Firebase para backend

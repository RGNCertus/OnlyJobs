ONLYJOBS - Rediseño de Sitio Web

Proyecto: Rediseño de Sitio Web Corporativo

Se llevó a cabo la transformación visual y funcional de un sitio web empresarial con enfoque en experiencia de usuario, rendimiento y diseño responsive.

Objetivos del proyecto:

  • Modernizar el diseño visual de la plataforma
  • Optimizar navegación y arquitectura de información
  • Adaptación móvil fluida
  • Reducción del tiempo de carga

Tecnologías empleadas:

  • HTML5, CSS3, JavaScript
  • React.js, Bootstrap
  • Figma, Google Fonts, GitHub

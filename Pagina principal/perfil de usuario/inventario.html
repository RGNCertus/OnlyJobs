Sistema de Inventario

Desarrollé un sistema web para gestionar el inventario de una tienda física. El objetivo fue mejorar el control del stock, evitar pérdidas de productos y facilitar el acceso a reportes en tiempo real.

Objetivos

  • Controlar las entradas y salidas de productos en tiempo real.
  • Generar alertas de stock bajo automáticamente.
  • Facilitar la búsqueda y registro de productos.
  • Permitir exportación de reportes en formatos PDF y Excel.

Herramientas y Tecnologías

  • PHP y MySQL para la lógica del sistema y la base de datos
  • HTML, CSS y JavaScript para la interfaz de usuario
  • Bootstrap para diseño responsive
  • Chart.js para gráficos estadísticos

Resultados

  • Reducción del 30% en errores de inventario.
  • Mayor rapidez en los procesos de reposición y revisión.
  • Uso diario por parte del personal sin necesidad de soporte técnico constante.

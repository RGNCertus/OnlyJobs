ONLYJOBS - Proyecto: Rediseño de Sitio Web

Rediseño de Sitio Web Corporativo

Este proyecto consistió en la renovación completa del sitio web de una empresa de tecnología. El objetivo principal fue mejorar la experiencia del usuario, actualizar el diseño visual y optimizar el rendimiento del sitio en todos los dispositivos.

Objetivos

  • Actualizar el diseño gráfico y la identidad visual.
  • Hacer el sitio completamente responsive.
  • Optimizar tiempos de carga y accesibilidad.
  • Mejorar la estructura de navegación.

Herramientas y Tecnologías

  • HTML5, CSS3 y JavaScript
  • Frameworks: Bootstrap y Flexbox
  • Diseño UI: Figma
  • Pruebas: Lighthouse y PageSpeed Insights

Resultados

  • 40% más de tiempo promedio de permanencia del usuario.
  • 25% más de conversiones mensuales.
  • Reducción del tiempo de carga en un 60%.
